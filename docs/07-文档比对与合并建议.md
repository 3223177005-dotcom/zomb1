## 五、维护规则（写进流程）

| 规则 | 说明 |
|---|---|
| 单一事实源 | 数值只在 02 或 03 出现一次，别处引用链接 |
| 改动即回填 | 改代码/数值/尺寸 → 同一次提交改文档，并更新本文的冲突表 |
| 术语先行 | 新词先加进 `00` 术语表，再进正文 |
| 待补充占位 | 不确定就写「（待补充：…）」，禁止编数 |
| 归档不删除 | 过时文档移到 `docs/archive/` 并在头部标注废弃原因 |
