# 01 · 项目定位与卖点

> 术语以 [`00-索引与术语.md`](00-索引与术语.md) 为准。

## 一、一句话定位

**《余日无多》是一款「搜打撤 + 刷宝构筑（BD）」的像素 2D 硬核 roguelike RPG 小游戏**：
带一把枪进废城，在 100 血、50 kg、12+30 格的夹缝里搜刮、交火、改装，活着走到撤离点把东西带出来；死了本局清零。

| 维度 | 定位 | 边界（明确不做） |
|---|---|---|
| 类型 | RPG 小游戏；局内是搜索-战斗-撤离的循环 | 不做开放世界、不做长线剧情线 |
| 视角/画风 | 像素 2D，俯视，32×32 世界格 | 不做等距、不做 3D、不做 HD-2D |
| 玩法支柱 | 搜打撤 / 生存 / 刷宝构筑（BD）/ 硬核 roguelike | 不做基地建造、不做多人联机 |
| 单局时长 | 5–15 分钟（一张 48×32 格地图） | 不做长局战役 |
| 难度取向 | 偏硬核：死亡清空、弹药有限、负重卡死 | 不做无脑割草 |
| 平台 | 桌面（Windows 已导出，macOS 有导出说明） | 手机端（待补充：是否立项） |
| 引擎/语言 | Godot 4.7.2（mono）+ C#，`dotnet build` | 不改引擎、不引入第三方框架 |

## 三、卖点（按「一句话能讲清」排序）

1. **一局三件事都成立**：搜到东西不算赢，打到东西不算赢，**撤出去才算**——这是本作和其他打丧尸小游戏的分水岭。
2. **改装驱动 BD**：同一把 SVD，装消音器（降音噪）还是装扩容弹匣（10→更多），决定你是「 stealth 搜刮」还是「正面刚枪」；附件槽位是硬约束（SVD 只开 3 个槽）。
3. **背包即压力**：格子 + 负重双限，捡什么、扔什么、为一件金条腾 1×1 还是丢 5 发 7.62×54R，是每局的真实决策。
4. **硬核但不冗长**：不做饥饿/口渴/体温，压力来自**弹药、负重、撤离倒计时**，一局 5–15 分钟。
5. **像素 2D 的清晰度红利**：32px 世界格 + 32px 图标 + 40px UI 格，1:1 不缩放（见 03）。

## 四、目标玩家

| 玩家画像 | 为什么会被吸引 | 可能的抱怨 |
|---|---|---|
| 玩过《逃离塔科夫》《暗区突围》，但没时间 | 5–15 分钟一局的搜打撤，规则更轻 | 「没有保险箱/市场」 |
| 喜欢《暗黑》类刷宝 + 构筑 | 附件改装 + 数值搭配 | 「没有随机词条，刷不出惊喜」 |
| 喜欢硬核 roguelike | 死亡清空、资源紧张 | 「没有元进度，重复动力弱」 |
| 像素游戏爱好者 | 干净的 32px 像素、清晰的 UI | 「内容量偏少」 |

## 六、竞品/参照（只作定位参照，不作抄袭目标）

| 参照 | 借什么 | 不借什么 |
|---|---|---|
| 逃离塔科夫 / 暗区突围 | 搜打撤的「撤出去才算数」、负重与格子压力 | 复杂的市场、保险、耐久经济 |
| 暗黑破坏神系 | 掉落 → 变强的正反馈、稀有度分档 | 随机词条的词缀池（当前未做） |
| 泰拉瑞亚 | 武器独立旋转、手持表现的爽感 | 沙盒建造 |
| CDDA | 像素素材与地形自动拼接规范 | 复杂的身体部位/生存模拟 |
