# 03 · 美术与像素规格

> 术语以 [`00-索引与术语.md`](00-索引与术语.md) 为准。本文是**硬规格**：改图前先对照本表，改完必须回填。

## 一、渲染总原则

| 项 | 规格 | 位置 |
|---|---|---|
| 纹理过滤 | **最近邻**（`default_texture_filter=0`） | `project.godot` |
| 导入 | 无损（`compress/mode=0`）、**不开 mipmap** | `*.png.import` |
| 世界格 | **32×32 px**（`Game.CellSize=32`） | `scripts/Game.cs` |
| 相机 | `Zoom = 1`（每格 32 屏幕像素） | `Game.SetupWorldZoom` |
| 逻辑分辨率 | **1280×720**（UI 按此布局，整数缩放） | `project.godot` |
| 缩放 | 只允许**整数倍**显示；禁止 16→26 这类非整数缩放 | 见 §4 |

## 三、世界内缩放约定（重要）

世界格从 16px 升到 32px 后，以下资源在**代码里显式 2×**，美术不必重画也能对齐：

| 对象 | 缩放 | 代码位置 |
|---|---|---|
| 角色 / 丧尸 | `Sprite2D.Scale = 2` | `Player.BuildSprite`、`Enemy` |
| 武器（旧贴图） | `_gun.Scale = 2` | `WeaponVisual._Ready` |
| 武器（CDDA） | `_gun.Scale = 2` → 实际 54×14 | `WeaponVisual.ApplyCdda` |
| 箱子 / 尸体 | `Scale = 2` | `Game.AddChestSprite`、`Enemy.SpawnCorpse` |

> **例外（不缩放）**：树 `assets/sprites/objects32/zs/s_tree*.png` 是 **32×80 原生**素材，
> 按 1:1 显示（`WorldProps`）；树干碰撞是 **14×10 的矩形**，挂在**道具层**上
> （不是精灵下面 —— 挂精灵下会连带吃缩放，半径和圆心都会被放大）。
> 回归测试：`tests/TreeCollisionSelfTest.tscn`。玩家碰撞盒相对精灵下移 4px
> （贴图上方有 2px 透明留白 ×2 缩放），否则会被挡在离树干 4px 处，看起来像"树下方有条走不了"。

> 规则：**新增任何世界贴图，若来源是 16px 素材，必须显式 ×2**，否则会只有半格大（这个坑踩过一次）。

## 四、UI 尺寸（`scripts/ui/core/UiMetrics.cs` 是唯一来源）

| 项 | 数值 | 说明 |
|---|---|---|
| 基准分辨率 | **1280×720** | `project.godot` viewport；`scale_mode=integer` |
| 字号阶梯 | 12 / 14 / 16 / 20 / 24 / 32 | 像素字体 12px 网格，12 的整数倍最锐利 |
| 网格格子 | **48 px**（`UiMetrics.CellPx`） | 48 − 边框 2 − 内边距 = 32 图标原尺寸 |
| 物品行图标 | **32 px**（`UiMetrics.ItemIconPx`） | 行高 44 |
| 槽内图标框 | **44 px**（`UiMetrics.IconBox`） | 装备行 / 快捷槽 |
| HUD 布局 | **四角贴边、纯图标**：左上生存盒 172×118、右下武器盒 184×58、底部快捷栏 68×3、右上浮窗 260×132 | `UiMetrics.Hud*`；12×12 图标 1:1 |

> **减字约定（UI 通用）**：能靠**图标 / 格子 / 进度条**看懂的信息一律不写汉字 ——
> 背包格块内不印物品名（悬停看 Tooltip）、区块标题不报 `[x/y 格 · W×H]`、
> 装备行不写物品全名（只留 `100%`）、快捷栏只有格号 + 图标、HUD 负重只留 `18.6kg`。
| 进度条高度 | 生命 16 / 细条 8 / 耐久 8 / 微型 6 | `UiMetrics.Bar*` |
| 面板版式 | 左 0.08、右 0.92（搜索时 0.98）、上 0.05、下 0.95 | 容器化自适应，改 `UiMetrics.Panel*` |

## 四之二、UI 配色规范（**旧帆布 + 战地档案卡**浅色系）

浅色底的理由：物品图标本身是**深黑铁色 + 1px 黑描边**，放在浅米色格子里轮廓才跳得出来；
深色底会把枪械 / 钢盔 / 护甲糊成一团。文字一律用**深色印章色**，只有压在深色进度条或
世界地图上的字才用亮米白 + 深描边。

统一由 `tools/gen_hud_icons.py` 生成，改色只改脚本再重跑，**不要手动描图**。

> 浅底上白字发飘、冷蓝底与暖黄废土割裂 —— 这两种都会瞬间显出"AI 默认模板"感。

**禁止**：把 32px 图标显示在 26/34/28 这类尺寸里（会产生大小不一的像素块）；不要在 UI 里写死字号/尺寸，一律走 `UiMetrics`。

## 五、地形自动拼接（16 掩码）

- 掩码定义：上=1 右=2 下=4 左=8（`MapLayout.MaskAt`），同种地形或同为实心墙算连通。
- 图集布局：`X = 掩码 0..15`，`Y = 地形序号 0..7`。
- 生成脚本：`tools/build_terrain_atlas.py`，朝向校准靠 `END_ORDER / CORNER_ORDER / TCONN_ORDER / EDGE_ORDER` 四个常量。
- 墙的取源：砖墙 = 自制 16px 2×；混凝土外墙 = CDDA `t_wall`（`WALL_SOURCE` 控制）。
