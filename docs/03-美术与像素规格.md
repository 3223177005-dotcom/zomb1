# 03 · 美术与像素规格

> 术语以 [`00-索引与术语.md`](00-索引与术语.md) 为准。本文是**硬规格**：改图前先对照本表，改完必须回填。

## 一、渲染总原则

| 项 | 规格 | 位置 |
|---|---|---|
| 纹理过滤 | **最近邻**（`default_texture_filter=0`） | `project.godot` |
| 导入 | 无损（`compress/mode=0`）、**不开 mipmap** | `*.png.import` |
| 世界格 | **32×32 px**（`Game.CellSize=32`） | `scripts/Game.cs` |
| 相机 | `Zoom = 1`（每格 32 屏幕像素） | `Game.SetupWorldZoom` |
| 逻辑分辨率 | 960×540（UI 按此布局） | `project.godot` |
| 缩放 | 只允许**整数倍**显示；禁止 16→26 这类非整数缩放 | 见 §4 |

## 三、世界内缩放约定（重要）

世界格从 16px 升到 32px 后，以下资源在**代码里显式 2×**，美术不必重画也能对齐：

| 对象 | 缩放 | 代码位置 |
|---|---|---|
| 角色 / 丧尸 | `Sprite2D.Scale = 2` | `Player.BuildSprite`、`Enemy` |
| 武器（旧贴图） | `_gun.Scale = 2` | `WeaponVisual._Ready` |
| 武器（CDDA） | `_gun.Scale = 2` → 实际 54×14 | `WeaponVisual.ApplyCdda` |
| 箱子 / 尸体 | `Scale = 2` | `Game.AddChestSprite`、`Enemy.SpawnCorpse` |

> 规则：**新增任何世界贴图，若来源是 16px 素材，必须显式 ×2**，否则会只有半格大（这个坑踩过一次）。

## 四、UI 尺寸（与图标 1:1）

| 项 | 数值 | 说明 |
|---|---|---|
| 网格格子 | **40 px**（`GridPanel.CellPx`） | 40 − 边框 2 − 内边距 6 = 32 = 图标原尺寸 |
| 物品行图标 | **32 px**（`ItemRow.IconSize`） | 行高 38 |
| 口袋 / 背包 / 容器 | 4×3 / 6×5 / 6×5 | 见 02 §2 |

**禁止**：把 32px 图标显示在 26/34/28 这类尺寸里（会产生大小不一的像素块）。

## 五、地形自动拼接（16 掩码）

- 掩码定义：上=1 右=2 下=4 左=8（`MapLayout.MaskAt`），同种地形或同为实心墙算连通。
- 图集布局：`X = 掩码 0..15`，`Y = 地形序号 0..7`。
- 生成脚本：`tools/build_terrain_atlas.py`，朝向校准靠 `END_ORDER / CORNER_ORDER / TCONN_ORDER / EDGE_ORDER` 四个常量。
- 墙的取源：砖墙 = 自制 16px 2×；混凝土外墙 = CDDA `t_wall`（`WALL_SOURCE` 控制）。
