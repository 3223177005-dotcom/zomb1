## 二、术语表（全文强制统一）

| 术语 | 定义 | 允许的写法 |
|---|---|---|
| **搜打撤** | 一局的核心结构：**搜**（搜刮尸体/容器）→ **打**（与丧尸交战）→ **撤**（在撤离点坚持 5 秒带出战利品）。三者必须都成立，缺一项就不叫搜打撤 | 搜打撤；不写「打宝撤离」「搜索射击」 |
| **生存** | 局内的资源压力：弹药、负重（50 kg 上限）、血量（100 HP）、空间（口袋 12 格 / 背包 30 格）。**不做饥饿/口渴**（见 06 待决） | 生存；不写「硬核生存模拟」 |
| **刷宝构筑（BD）** | 通过**掉落 → 改装（附件）→ 数值搭配**形成一套打法。当前深度是「固定附件 + 固定数值」，**没有随机词条**（见 06） | 刷宝构筑、BD；首次出现写「刷宝构筑（BD）」，后文可用 BD |
| **硬核 roguelike** | 死亡即**本局清空**：没有保险箱、没有跨局仓库、没有元进度（当前实现见 02 §5） | 硬核 roguelike；不写「肉鸽」「Roguelite」（后者暗示元进度） |
| **像素 2D** | 2D 俯视像素画；世界格 **32×32 px**，最近邻过滤，整数倍缩放 | 像素 2D；不写「像素风 2.5D」「HD-2D」 |
| **世界格** | 地图的逻辑单元，32×32 世界像素；地图 48×32 格 | 世界格 / cell |
| **口袋 / 背包 / 容器** | 口袋 = 4×3（12 格，随身固定）；背包 = 6×5（30 格，可换）；容器 = 搜刮点的 6×5 格 | 口袋、背包、容器 |
| **撤离点** | 地图 (23,29) 起的 2×2 格区域，站满 5 秒触发结算 | 撤离点 |
| **结算** | 撤离成功后弹出的面板：列出带出物、件数、总价值、负重 | 结算；不写「结算界面」 |

> 术语变更必须同时改本表 + `01`/`02` 正文，禁止单方面改名。
