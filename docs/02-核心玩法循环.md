# 02 · 核心玩法循环

> 术语以 [`00-索引与术语.md`](00-索引与术语.md) 为准。数值均来自代码/`.tres`，未确认项标「（待补充：…）」。

## 一、一局的完整循环

```
主菜单 → 进入地图（48×32 格）
   ↓
[搜] 搜刮：尸体 / 屋内容器 → 逐格揭示 → 拖进背包
   ↓
[打] 交战：SVD 射击 / 匕首近战，消耗弹药与血量
   ↓
[撤] 撤离点站 5 秒（离开清零）→ 结算面板 → 回主菜单
   ↑                                    ↓
   └──────────── 死亡：3 秒后直接回主菜单（无结算、无保留） ───────┘
```

## 二、生存层（局内资源压力）

| 资源 | 数值 | 来源 | 说明 |
|---|---|---|---|
| 生命 | 100 | `Player` | 归零 → 死亡流程（§5） |
| 负重上限 | 50 kg | `Player` | 超重无法继续拾取 |
| 口袋 | 4×3 = 12 格 | `EquipmentPanel` | 随身固定，不可换 |
| 背包 | 6×5 = 30 格 | `data/containers/backpack.tres` | 可替换容器 |
| 搜刮容器 | 6×5 = 30 格 | `WorldItems.LootGridW/H` | 每个搜刮点独立 |
| 移动速度 | 走 240 / 跑 400 px/s | `Player` | 瞄准时 ×0.5 |
| 交互半径 | 64 px | `Player.InteractRange` | 朝向前方 120° 优先 |

**设计原则**：不做饥饿、口渴、体温、耐久（见 06 待决 Q3）。生存压力只来自「血 / 负重 / 弹药 / 格子」四件事，目的是把一局压在 5–15 分钟。

## 三、搜（搜刮）

| 项 | 规则 | 依据 |
|---|---|---|
| 搜刮点类型 | 屋内容器（箱子/冰箱等 16px 物件，2× 放大后 32px）、丧尸尸体 | `Game.SpawnChests`、`Enemy.SpawnCorpse` |

## 五、硬核 roguelike：死亡与重生规则（当前实现）

| 事件 | 规则 | 依据 |
|---|---|---|
| 撤离成功 | 站满 5 秒 → 结算面板（带出物清单 + 件数/总价值/负重）→ 回主菜单 | `ExtractionZone.Tick`、`ResultPanel` |
| 撤离失败 | 中途离开区域 → 计时**清零**，必须老老实实站满 | 同上 |
| 死亡 | 人物变暗红、发 `PlayerDied` 信号、**3 秒后回主菜单** | `Player.Die()` |
| 死亡后保留 | **无**：无仓库、无保险箱、无元进度（`SaveManager` 未接入） | 代码检索 `SaveManager` 引用数 = 0 |
| 重新开始 | 回主菜单后重新开一局（地图与掉落**不保证随机**，见 06 Q2） | `SceneManager.GotoMainMenu` |

> **因此本作是「硬核 roguelike」而不是「Roguelite」**：没有跨局成长，靠玩家熟练度和局内决策。

## 七、单局节奏（目标体验）

| 阶段 | 时长 | 玩家在做什么 | 情绪 |
|---|---|---|---|
| 入场 | 0–1 min | 认地图、找屋子 | 谨慎 |
| 前中期 | 1–6 min | 搜箱子、清小股丧尸、算负重 | 贪婪与克制的拉扯 |
| 后期 | 6–12 min | 背包快满、弹药见底、决定「再搜一间还是撤」 | 紧张 |
| 撤离 | 最后 5 s | 站在撤离点挨打 | 爽点 |
