> 技术文档。术语以 [`00-索引与术语.md`](00-索引与术语.md) 为准。命令均在项目根目录 `test_1/新建游戏项目` 下执行。

## 一、技术栈与三条命令

| 项 | 值 |
|---|---|
| 引擎 | Godot 4.7.2（mono） |
| 语言 | C#（.NET） |
| 项目文件 | `ZombieExtraction.csproj`、`project.godot` |

```powershell
# 构建（日常）
dotnet build

# 跑游戏
D:\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64_console.exe --path . res://scenes/game.tscn

# 跑自测（50 项，必须全绿）
D:\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64_console.exe --headless --path . res://tests/GridSelfTest.tscn

# 新增/替换图片后必须先导入，否则贴图为空
D:\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64_console.exe --headless --path . --import

# 导出用构建配置
dotnet build -c ExportRelease
```

> ⚠️ **构建失败时 Godot 仍会用旧 dll 启动**，表现为「改了没反应 / 脚本类找不到」。先确认 `0 错误` 再看运行结果。

## 三、分层与职责

| 层 | 类 | 职责 | 不该做的事 |
|---|---|---|---|
| 启动/总装 | `Game` | 建地图、放箱子、撤离点、结算面板、调试掉落 | 不承载玩法规则 |
| 角色 | `Player` | 输入 → 移动/瞄准/射击/拾取/死亡 | 不直接改 UI 内部 |
| 敌人 | `Enemy` | 感知、寻路、攻击、尸体与掉落 | 不管玩家的背包 |
| 武器 | `Weapon` / `MeleeWeapon` / `WeaponVisual` | 弹道、散布、换弹；**纯表现**的枪贴图与枪焰 | `WeaponVisual` 不参与命中判定 |
| 物品/背包 | `Inventory` / `GridInventory` / `ItemStack` | 格子占位、堆叠、旋转、拆分 | 不碰节点树 |
| 改装 | `WeaponMods` / `AttachmentFinder` / `AttachmentData` | 槽位匹配、数值叠加、递归找配件 | 不直接写日志/UI |
| 世界 | `MapLayout` / `MapGrid` / `WorldItems` / `ExtractionZone` | 地形数据、格坐标、地面物品、撤离计时 | 不画 UI |
| UI | `EquipmentPanel` / `GridPanel` / `ModifyPanel` … | 拖拽、悬停、提示、结算 | 不写玩法数值 |
| 全局 | `EventBus` / `ItemDatabase` / `NavigationManager` / `SceneManager` | 信号总线、物品库、寻路网格、场景跳转 | — |

## 四、数据驱动：怎么加内容

### 4.1 加一件物品

1. `data/items.json` 追加一条：`Id`、`Name`、`Category`、`GridW/GridH`、`Weight`、`IconPath`、`Rarity`、`Value` 等；
2. 图标放 `assets/sprites/items32/<id>.png`（32×32）；
3. 若可掉落，加进 `scripts/world/ZombieLoot.cs` 的 `Table`（权重）；
4. `--import` → `dotnet build` → 跑自测。

### 4.2 加一把枪

1. `data/guns/<id>.tres`（`GunData`：伤害、射速、弹匣、换弹、弹道、音噪、口径、开火模式）；
2. 若要手持外观：`assets/sprites/weapons_cdda/<id>.png`（纯枪横向），`WeaponVisual.SetGunItem` 会按 id 自动加载；
3. 若要开槽：在 `.tres` 的 `Slots` 里声明槽位（未声明 = 关闭）；
4. `data/items.json` 里登记同 id 的物品，指向该枪的 `RangedWeaponData`。

### 4.3 加一种地形

1. `MapLayout.Terrain` 加枚举（顺序 = 图集行号）；
2. `tools/build_terrain_atlas.py` 的 `TERRAINS` 加一行（CDDA id + 是否自动拼接）；
3. 重跑脚本 → `--import`。

## 七、已知技术债

1. `Game.CellSize` 从 16 改 32 时，所有像素常量（速度/射程/视野）被迫 ×2，**没有集中配置**，新增常量容易漏。
2. 世界贴图 2× 缩放散落在 4 处（角色/丧尸/武器/物件），新增贴图容易漏（见 03 §3）。
3. `GameManager` / `SaveManager` / `AudioManager` 是空壳，命名会误导新人。
4. 无 `README`/CI，构建与自测靠口口相传（本页即为补充）。
5. 地图是**硬编码布局**（`MapLayout.Build()`），不是关卡文件。
